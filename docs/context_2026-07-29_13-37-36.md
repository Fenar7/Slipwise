## 2. Recent Technical Fixes & Enhancements

### A. Next.js Edge Runtime Crypto Fix (MFA & TOTP)
Next.js Middleware compilation was crashing due to `import crypto from "crypto"` and `Buffer` usage inside authentication utilities bundled for the Edge Isolate Runtime.
- **Resolution**: Refactored `src/lib/mfa/token.ts` and `src/lib/totp/challenge-session.ts` to exclusively use native **W3C Web Crypto APIs** (`globalThis.crypto.subtle`, `TextEncoder`, `btoa`, `atob`).
- **Caller Updates**: Refactored HMAC token generation to be asynchronous and updated all dependent Next.js server actions, API routes, and Vitest test suites to use `await`.
- **Status**: Edge Middleware (`src/middleware.ts`) now compiles flawlessly in `npx next build`. All 41 related authentication tests pass completely. (Commit: `a9c6f431`).
